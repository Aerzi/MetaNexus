Role: Lead Creative Technologist (互动创意总监)

Task: 
在“Paper Grunge”风格的基础上，将结果页升级为“动态精神病历档案”。
核心目标：增加“伪科学的数据可视化”和“真实的物理质感”。

1. 技术栈升级:
- 引入 **Recharts** 绘制六维雷达图。
- 引入 **Framer Motion** 实现物理打印效果。
- 引入 **react-tilt** (或自定义 hook) 实现鼠标/陀螺仪的视差跟随效果。

2. UI/UX 深度重构:

   A. 布局结构 (从上到下):
      - 顶部: 档案编号 (NO.2026-XXXX) + 条形码 (Barcode Font)。
      - 核心区: 
         - 左侧: 巨大的马种名称 (Serif Font, 粗糙边缘)。
         - 右侧: **六维雷达图 (Radar Chart)**。
            - 轴: [发疯, 耐磨, 摸鱼, 背锅, 伪装, 离职]。
            - 配色: 网格线为浅灰色，数据区域为半透明的 #FF4400 (警示橙)。
      - 底部: 医生手写评语 (Handwritten Font) + 签名。
      - 盖章: 这是一个绝对定位的红色印章 SVG，使用 mix-blend-mode: multiply (正片叠底) 模拟真实油墨渗透。

   B. 交互与动效 (The "Wow" Factor):
      - **进场动画:** 模拟热敏打印机。整个卡片从上方 mask 区域缓缓划出 (Y轴位移)，带有顿挫感。
      - **盖章动画:** 打印完成后，印章从屏幕外以 3倍 scale 缩小砸向纸面，伴随轻微的 rotate 抖动。
      - **视差悬浮:** 整个卡片响应鼠标/手机倾斜。文字层、雷达图层、印章层 Z轴分离，产生 3D 景深感。

3. 视觉细节 (Texture):
- 纸张边缘: 使用 CSS clip-path 生成不规则的锯齿状撕裂边缘 (Torn Paper Effect)。
- 纸张纹理: 叠加一层 SVG Noise Filter，透明度 0.4，让图表看起来也是画在糙纸上的。

4. 动态数据生成逻辑 (示例):
- 罗马: { 发疯: 20, 耐磨: 100, 背锅: 100, 离职: 10 } (典型的老黄牛)
- 卷你马: { 发疯: 80, 耐磨: 90, 摸鱼: 0, 离职: 5 } (极度焦虑)
- 爱马仕: { 发疯: 50, 伪装: 100, 摸鱼: 80, 耐磨: 20 } (精致利己)
