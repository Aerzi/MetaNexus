## 1. 产品核心：视觉即正义

* **目标：** 通过 **HSL 算法**生成具有“酸性设计”感的动态分享卡片。
* **交互逻辑：** 5 道极简扎心题  后端逻辑计算  叠加随机数种子  生成唯一“色值码”与“马画像”。

### 附：HSL 随机色彩生成逻辑（确保 Cursor 没写歪）

```javascript
// 核心逻辑参考
const generateStyle = (points, rarity) => {
  let h;
  if (points > 15) h = 280; // 罗马紫
  else if (points > 10) h = 30; // 橙色爱马仕
  else h = 160; // 卷王绿

  const s = rarity > 90 ? 90 : 40 + (rarity % 30); // 稀有度越高越鲜艳
  const l = 60; // 保持亮度一致，确保文字可读
  return `hsl(${h}, ${s}%, ${l}%)`;
};

```
